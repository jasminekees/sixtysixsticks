One-time setup

Our 66 stores your logs in a free Firebase database instead of relying on Claude, so this file works for both of you on any plan, forever — but it needs your own free Firebase project connected first.

Step 1 — create a project
  1. Go to console.firebase.google.com and sign in with any Google account.
  2. Click Add project, name it anything (e.g. "our-66"), and skip Google Analytics.
Step 2 — turn on Firestore
  1. In the project, open Build > Firestore Database > Create database.
  2. Choose production mode and any region close to you.
Step 3 — set the rules

Open the Rules tab in Firestore and replace everything with this, then click Publish:

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /our66/{document=**} { allow read, write: if true; } } }

This keeps your data scoped to this app only — but anyone who has this file can read or write it, same trust level as sharing a link. Don't use it for anything sensitive.

Step 4 — connect this file
  1. Back in Project settings (gear icon) → General → scroll to "Your apps" → click the web icon </> → register an app (any nickname, no hosting needed).
  2. Copy the firebaseConfig object it shows you.
  3. Open this downloaded HTML file in a text editor, find PASTE_YOUR_FIREBASE_CONFIG_HERE near the top of the script, and paste your config in its place.
  4. Save the file and reopen it in your browser.

Send Olivia the exact same file (with your pasted config already in it) so you're both pointed at the same database.
